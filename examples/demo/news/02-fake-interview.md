# Fake job interviews deliver malware through look-alike npm packages (fictional)

Developers given take-home tests by a fake hiring company were told to install packages such as occupai-demo-anim and occupai-demo-anim-js. The packages ran a credential stealer on install. Some also added a VS Code task that runs when the folder opens. Treat any machine that installed them as compromised.
